## See it work

```bash
curl -X POST https://your-host/v1/trade/evaluate \
  -H "X-API-Key: $POKEMON_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"offered_pokemon": "Charizard", "requested_pokemon": "Dragonite"}'
```

Trade Advisor routes this to Market Analyst, Legitimacy Guard, and Battle Strategy Advisor before
answering — the [Architecture](/architecture/) page walks through the full delegation chain.
